# Komado — Store 掲載原稿

## 短い説明

ZIP・PDF・画像フォルダを、そのまま読める漫画ビューワー。

## 説明

漫画を開いて、読むことに集中。

Komado は、手元の ZIP・CBZ・PDF・画像フォルダを読む Windows 11 向けの漫画ビューワーです。ファイルやフォルダをウィンドウにドロップすれば、すぐに読み始められます。ZIP は事前に解凍する必要がありません。

自動表示では、表紙は中央に1枚、縦長のページは見開き、横長のページは1枚で表示。単ページと見開きを手動で選ぶこともできます。ページ送りの方向は「左で次へ」「右で次へ」から選べます。

クリック、マウスホイール、矢印キーでページを送り、キーの長押しで連続して読み進められます。読書中はシークバーを隠して画面を広く使い、中央をクリックしたときだけ表示できます。

最近開いた作品は表紙のサムネイルから開き直せます。ウィンドウサイズや表示設定も次回起動時に復元します。

対応形式：ZIP、CBZ、PDF、PNG、JPEG、BMP、GIF、TIFF、および画像を含むフォルダ。
GIF・複数フレーム TIFF は最初のフレームを表示します。暗号化 ZIP、パスワード付き PDF、WebP、AVIF には対応していません。

漫画の配信・購入機能はありません。閲覧するファイルはご自身で用意してください。

## 機能

- ZIP を解凍せずに閲覧
- PDF と画像フォルダの読み込み
- 画像の向きに合わせた単ページ・見開きの自動切り替え
- 左右のページ送り方向を切り替え
- マウス・キーボードによるページ送りと全画面表示
- 最近開いた10作品を表紙サムネイルで表示

Komado の初回リリースです。ZIP・CBZ・PDF・画像フォルダの閲覧、自動見開き、送り方向の切り替え、最近開いた作品の表示に対応しました。

## スクリーンショットのキャプション

1. 漫画を主役にした、シンプルな読書画面。
2. 中央をクリックしてシークバーを表示。読みたいページへ移動できます。

## システム要件

Windows 11、x64。.NET ランタイムは Store 版に同梱しています。
