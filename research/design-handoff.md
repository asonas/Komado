各画面は 1440 × 960。日本語フォントは Noto Sans JP。暗いキャンバス、操作ボタンを統合した薄いタイトルバー、淡い緑のアクセントを使う。「開く」ボタンとファイル名表示は置かず、別段の上部ツールバーも削除する。

漫画部分は配置確認用に作成したオリジナルの簡略絵コンテ。ページ数もサンプルであり、実際の ZIP を読み込んだものではない。

最上部には元のボタン・切り替え UI をそのまま配置する。メニューバー化はしない。読書中の通常ウィンドウでは常時表示し、中央クリックによるシークバー表示とは独立させる。

| UI | 項目 |
| --- | --- |
| セグメント切り替え | 自動／単ページ／見開き。初期状態は自動 |
| 表示倍率のドロップダウン | 画面に合わせる |
| 送り方向ボタン | 現在の「左で次へ」を表示し、クリックすると左右の選択肢を開く |
| アイコンボタン | 全画面 |

## 操作仕様案

| 操作 | 動作 |
| --- | --- |
| ZIP を開く | ウィンドウへドロップする。Ctrl + O からのファイル選択も維持する |
| フォルダを開く | ウィンドウへドロップする |
| ドロップ | ウィンドウ全体で ZIP または解凍済み画像フォルダを受け付ける。開始画面・読書中のどちらでも利用でき、中央領域、漫画、余白、ツールバーの上でも開ける。読書中は読み込み成功後にドロップした作品へ切り替える |
| 左で次へ | 左矢印・S・J・読書領域の左 1/3 のクリックで次へ。右矢印・F・L・右 1/3 のクリックで前へ。見開きは右に先のページ、左に次のページ |
| 右で次へ | 上記の左右を反転。表示中のページ位置は維持する |
| スクロール | 読書領域でマウスホイールを下に回すと次へ、上に回すと前へ。左右の送り方向設定には依存しない |
| ページ送りキーの長押し | 押した直後に 1 回送り、Windows のキー待ち時間の後に連続して送る。画像表示中は長押しによる次の送りを待ち、表示のキャンセルを繰り返さない。キーを離すかウィンドウが非アクティブになると停止する |
| 単ページ／見開き | 同じ読書位置のままページ配置を切り替える |
| 自動表示 | 幅が高さを超える画像は中央に単独表示し、縦長・正方形は次の縦長・正方形と見開きにする。次が横長なら両者を組にしない。読み込み時の寸法を記録して前後の移動量に反映し、横長画像の前後でページを飛ばさない。表紙は自動でも単独表示する |
| 表紙 | 1 ページ目は中央に 1 枚だけ表示する。見開きでも表紙は単独にし、次は 2・3 ページ目、以降は 4・5 ページ目の順に表示する。2・3 ページ目から戻ると表紙へ戻る |
| 画面に合わせる | ページ全体が読書領域に収まる倍率にする |
| 全画面 | 全画面読書へ切り替える。Esc で戻る |
| 中央クリック | 読書領域の中央 1/3 をクリックするとシークバーを表示し、再クリックで隠す。ページは送らない。最上部の操作ボタンは表示状態を変えない |
| シークバー | 通常は非表示。中央クリックで下中央の角丸ボックスに重ねて表示する。ページ位置へ移動でき、開始側は送り方向に合わせる |
| 表示位置の同期 | 画像とページ番号とシークバーを同時に更新する。未読み込みの移動先では元の表示位置を保ち、画像が用意できた時点でまとめて切り替える。連続シークは最新の移動先へ追従する |
| アプリの再起動 | 前回終了時のウィンドウサイズ (幅・高さ) を自動で復元する。サイズ変更後はそのサイズを記憶し、設定操作は不要とする |

Figma は静的な画面案。対応する Windows アプリは `src/MangaViewer` に実装した。確認結果と性能測定の範囲は [implementation-checks.md](implementation-checks.md) に記録している。

開始画面の案内は「このウィンドウに ZIP またはフォルダをドロップ」とする。中央だけがドロップ対象に見える点線枠は置かない。実装時は開始画面と読書中の両方で、ZIP とフォルダを漫画・余白・ツールバーの各領域へドロップして開けることを確認する。

開始画面ではドロップ案内の下へ「最近開いたファイル」を表示する。ZIP・フォルダを新しい順に最大 10 件並べ、名前のクリックで開き直す。同じパスは重複させず先頭へ移動する。履歴がなければ一覧見出しも隠す。フルパスはツールチップに収め、画面の高さが足りないときはスクロールできるようにする。履歴はローカルに保存して次回起動時に復元し、開くのに失敗した項目は履歴へ追加しない。

## 構造確認

シークバーのボックスは設計上 640 × 56、角丸 12、下端から 24 の余白で水平中央に配置する。幅は最大 640 とし、狭いウィンドウでは左右に 24 ずつ余白を残せる幅まで縮める。ページ数とシーク操作をコンパクトにまとめ、左右の漫画を隠さない。

読書中は操作ボタンを統合したタイトルバーを除く縦の領域を漫画に使い、操作バー用の余白は確保しない。画像の縦横比を保ち、横幅に収まる範囲で高さを最大限使う。シークバーは漫画に重ねて表示し、表示・非表示で漫画のサイズや位置を変えない。通常ウィンドウではタイトルバーを残し、全画面ではタイトルバーも隠す。

ページ送りは次の対応で実装・検証する。クリックは左右のマウスボタンの区別ではなく、読書領域を横に 3 等分した左右の領域を左ボタンでクリックする操作とする。中央は操作バーの表示切り替え専用とする。漫画上と余白の両方を対象にし、ツールバーやメニュー、シークバーのクリックでページ送りやバーの表示切り替えを起こさない。入力欄やダイアログを操作中はページ送りキーを処理しない。

| 入力 | 左で次へ | 右で次へ |
| --- | --- | --- |
| 左 1/3 をクリック／←／S／J | 次へ | 前へ |
| 右 1/3 をクリック／→／F／L | 前へ | 次へ |
| 中央 1/3 をクリック | 操作バーの表示切り替え | 操作バーの表示切り替え |
| ホイール下 | 次へ | 次へ |
| ホイール上 | 前へ | 前へ |

ページ送り入力では、単ページ表示は 1 ページ、見開き表示は次または前の見開きへ移動する。最初・最後のページでは範囲外へ移動しない。実装時に各入力と両方向設定の組み合わせを確認する。中央クリックでページが変わらず、バーの表示前後で漫画の表示サイズと位置が変わらないことも確認する。

ウィンドウサイズの復元は実装時の検証項目とする。ウィンドウの幅と高さを変更して終了し、再起動すると同じサイズで開くことを確認する。Figma の 1440 × 960 は画面設計用の寸法であり、起動ごとに強制する固定サイズではない。

開始画面の中央アイコン・見出し・ドロップ案内は表示しない。最近開いた作品は正方形の表紙サムネイルとファイル名のカードで、左上からウィンドウ幅に合わせて並べる。高さに収まらない場合はスクロールする。サムネイルは 1 ページ目の縦横比を保ち、中央を正方形に切り抜く。クリックで開き直し、フルパスはツールチップで表示する。生成とキャッシュ保存はアプリがバックグラウンドで行う。

4 画面とも文字、ベクター、Auto Layout、ボタンのインスタンスで構成。画面全体を覆う画像レイヤーはない。テキストのフォントは Noto Sans JP で揃えている。読書画面は操作バー非表示・表示・方向設定メニュー表示の状態を用意する。
